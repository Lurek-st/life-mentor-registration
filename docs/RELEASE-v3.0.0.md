# v3.0.0 发布验证

日期：2026-10-13。范围：从公开 v2.0.0 升级到通用 v3.0.0；全部变更性测试使用虚构资料与隔离的本机数据库。没有对运行中的机构系统部署、写入名单或发送通知。

## 第一轮：功能、兼容性和数据

- 类型检查与前端、Worker 构建通过。
- 报名、取消、重复请求、响应丢失后的查回、容量下调、改期、归档恢复和工作人员并发修改通过。
- 本机 100 个请求竞争最后一席，只接受一个；500 个合成用户共用一个 IP 的提交全部成功，最终人数一致。
- 参会核对 11 组检查通过，覆盖未勾选保留待核对、原补记保留、并发冲突、批次回查、部分失败回滚、工号更正与单场/学期统计。
- 实际 v2 结构通过本机 D1 迁移；再次应用迁移不重复执行。原中文、前导零、请求凭证哈希、取消状态、时间和设置按字段核验保留。
- 随仓库交付的恢复命令通过旧 JSON 与新加密备份测试；错误密码、被改动文件、缺失核对表和已含记录的恢复目标会被拒绝。

## 第二轮：重新安装、实际操作和公开边界

- 从提交 `8af4861` 克隆到全新目录，不复制原 `node_modules`、私有配置、工作目录或数据库；`npm ci`、公开内容检查、构建和完整 `npm test` 通过。
- Chromium 实际点击验证中文/英文报名、详情外侧关闭、ICS 下载、工作人员核对、未报名者补录、总名单 XLSX 和备份再次认证、加密下载。手机 390px 和桌面 1440px、减少动效、无横向溢出和无页面运行错误检查通过。
- 移除原部署专用的英文标题例外逻辑，工作人员填写的英文标题正常展示；默认工号规则保持 v2 兼容，另以合成配置验证固定八位数字及邮箱后缀的前后端约束。
